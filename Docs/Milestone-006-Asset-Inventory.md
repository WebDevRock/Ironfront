# Milestone 006 — Asset Inventory and Licensing

**Summary:**
- No external, purchased, downloaded or AI-generated assets were used.
- No project files were sent to any external generator or service.
- Every new asset is **procedurally generated by code in this repository**. The generators are deterministic, so running the builders again reproduces the same assets.
- The only non-project content is Unity built-in engine resources, which are covered by the Unity licence the project already uses.

- **E**: Unity built-in engine resource (licensed with the Unity Editor).
- **X**: pre-existing project asset from Milestones 001–005, itself generated by the earlier builders.

## Licence information

- **External assets:** none, so no third-party licences apply.
- **Procedurally generated assets:** created by this project's own source code. They carry whatever licence the project owner chooses for the repository; there are no third-party rights in them.
- **Audio:** synthesised from scratch (noise, oscillators, filters, envelopes). It contains no samples, recordings or sample libraries.
- **Designs:** all vehicle, structure, emblem and UI designs are original. They are not based on Command & Conquer or any other franchise's models, logos, unit designs or audio.
- **Unity built-in resources:** used under the Unity Editor licence, as in Milestones 001–005.

## Repository impact

- Generated meshes are stored as text YAML assets (about 27 MB, mostly the backdrop ridges and props). The generators are deterministic, so rebuilding does not churn them.
- Textures total about 3 MB; audio about 4.4 MB (WAV source, compressed on import).

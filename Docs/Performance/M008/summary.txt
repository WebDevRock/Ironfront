M008 release benchmark, Windows player, 1280x720 windowed, one session (2026-10-12).
Map benchmark (-ironfrontMapBenchmark): each skirmish map loaded with spawn seed 1, computer commander running.
Phases (12 s each): opening = camera over the player's base; pan = camera sweeping the whole map;
battle = 50 vs 50 light/heavy tanks fighting in open ground near the map centre (camera on the fight).
Runs: fog on x2 (maps_run1.json, maps_run2.json), fog off (-fxNoFog) x2 (maps_nofog_run1/2.json), alternated.
maps_nofog_run1 was disturbed by machine load part-way (Green Divide battle 3.9 ms with a 246 ms spike, all
Blackstone phases ~3.3 ms including a static opening); its repeat run2 is consistent and is used below.
